# 範圍與隱私

這份筆記只保留新北市政府市長信箱的可重用操作經驗，不保存陳情人的姓名、
聯絡方式、地址、身分證字號、案件編號、案件查詢碼、驗證碼或信件連結。

# 卡住時保留表單

分類頁按下案件小類後，網址可能不變、畫面也暫時停留在分類清單。先等待數秒；
若仍未更新，按一次 `Esc` 停止載入，再重新讀取目前畫面。已驗證這樣可讓同一頁
顯示資料表單。不要先重整或重開頁面，避免清除已填內容。

# AngularJS 欄位必須觸發真實輸入事件

這個表單的文字框由 AngularJS 綁定。自動化的 `fill()` 或一次性文字注入可能讓
字串看起來已出現在欄位內，但頁面字數計數器仍為 `0/2000`，代表畫面值尚不能
作為送出模型已同步的證據。

可靠做法是先聚焦欄位，以 `Meta+A`、`Backspace` 清除既有值，再用
`pressSequentially()` 輸入。長文以約 50 字元的小段輸入；每段後讀取目前文字
長度並確認它仍是預期內容的前綴，再繼續剩餘字串。這也避免單次長輸入超過動作
期限後，重試整段造成重複內容。

電子信箱與行動電話可能因瀏覽器隱私遮罩而無法由自動化讀回明文。此時以欄位的
原生 validity、Angular `ng-valid-*` 狀態、可見遮罩格式，以及下一頁的資料檢視
結果交叉確認，不要把空的程式化讀值誤判成欄位未填。

# 驗證與完成證據

圖形驗證碼需在當下取得使用者同意後再代填，或讓使用者接手；不要為了更換圖形碼
而重整整份表單。通過圖形碼後，先在「檢視資料」頁完整核對，再於使用者最後確認
後按正式送出。

第一次正式送出只會產生待驗證案件並寄出電子郵件，不能當成受理完成。使用者完成
信箱驗證後，以新寄達的「市長信箱受理通知」為完成證據：通知必須明確寫出已完成
驗證、案件已列入處理流程，並提供案件編號與案件查詢碼。原本的驗證分頁可能不會
自動更新，因此不要只看它仍停留在驗證提示就判定失敗。

最後保存受理通知中案件資訊區塊的畫面與一份本機文字紀錄；兩者都放在工作輸出
目錄，且不要同步到共享記憶庫。
