- 低錯誤率的 Monte Carlo 先看觀察到多少事件、分布在多少個獨立樣本，再決定增加多少次。不把同張網格的格子當作獨立樣本；用每張網格的錯誤數算標準誤與區間。記下種子、樣本數、事件數和必要的執行參數。
- 在買更多運算時間或寫 GPU 版前，先量原程式並找可跳過的工作。當第一輪各條線的輸入獨立且輸出大多全零，可用精確分布抽取整條線的輸出遮罩，幾何跳距略過全零線，再跑後續解碼。保留線內的關聯，不能把輸出改抽成獨立 bits。用小案例對照原本逐格解碼，也核對抽樣機率。
- 已驗證案例：三個方向各長 8 的 extended Hamming、初始錯誤率 0.02。M5 的稀疏 C++ 版用 8 CPU 執行緒約 1.5 秒跑十億張，第三輪共 9,034 個錯誤，分布在 4,161 張。以網格為單位的近似 95% 區間包含精確遞迴；二次近似比模擬高約 19.5%。沒有測 GPU，時間不能拿來宣稱 CPU 與 GPU 的相對效能。
