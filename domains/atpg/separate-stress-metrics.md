# 沒有依據的 stress 加權分數應拆開定義

歷史助手質疑 ScanForge 將 toggle、duty bias 與 longest run 加權成單一 stress_score 的物理依據；使用者明確要求改成兩種 stress score，不要加權平均。

分別列出指標的量綱、時間範圍、物理假設及用途，不把 switching proxy 直接升格成老化或 IR-drop 證明。來源未附可核對文獻內容，不能採用幾乎所有文獻都如此或完全無爭議的斷言；兩種指標的最終公式與修改結果也尚未提供。
