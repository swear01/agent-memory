# 長時間比較先核對單一 analysis 與 portfolio

歷史助手準備再次跑 stock／VGuide portfolio 比較，使用者指出該比較已跑過，當次要的是純 CPAchecker 單一 config；助手隨後改查 predicateAnalysis 設定並提出新的 runner。

啟動前核對實際 config、兩 arm 的差異與已完成實驗，不以 mode 名稱代替設定身份。相同題庫、timeout 或同批執行不能補救比較問題選錯。來源只有更正與啟動提案，沒有最後結果；估計六小時及平行度不構成實測速度。
