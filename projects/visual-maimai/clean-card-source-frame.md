# 有缺陷的來源 still 會把錯誤帶進新動畫

歷史助手檢查五支影片開頭，自述兩支仍有巨大數字重疊與卡面偏移：一支直接沿用原動畫，另一支的新動畫底圖來自已包含缺陷的來源 still。

修整卡面前先檢查底圖本身；不能只因換成自製動畫就認為舊缺陷消失。當次計畫是以曲繪和文字重排，再更新抽幀規格與逐支驗證。來源僅完成盤點，沒有修改交付檔或逐幀獨立驗證。
