SCE-133 exposed a model gap on the original CBDK negative-timing Verilog. Native Innovus setup, hold, and all SRAM pulse checks passed at 1.780 ns. VCS still reported 1,138 TLATX1 setup/hold violations before any output. All of their clock cones traced to 11 TLATNCA gated-clock instances.

For the first failing latch, the saved RC/SDF expected a 313.3 ps CK-to-ECK fall delay from the TLATNCAX20 gate. The vendor simulation model defines the rising CK path only. Replaying the same VCS executable at 100 fs showed CK and ECK falling in the same time slot while enable and its latched value were high. The rising path took the annotated 365 ps. Omitting the falling arc from an SDF path walk predicted latch G to within 0.5 ps of the waveform. Its real D fell 151 ps before G, inside the annotated 159/−150 ps setup/hold window. The latch notifier changed and Q became X in that time slot. The later system stall was not traced back through every intervening state.

When propagated latch STA reports zero or time borrowing and post simulation first fails at a latch, trace its G driver back to the gate. Compare native CK/ECK edge arcs, the exact SDF instance section, and the original Verilog specify path by edge. An aggregate IOPATH annotation PASS does not establish that the falling edge traverses a valid specify path. Use the same compiled executable to observe gate CK/E/ECK and latch G/D/dG/dD/NOTIFIER/Q around the first event. Keep timing checks and notifiers enabled. Establish the cell-model edge gap before changing SRAM clocks or retiming latch data.

SCE-137 verified a stock physical replacement for one affected gate. TLATNX1 provides both true Q and QN, NAND3BX2 gates CK with Q and inverted QN, and INVX20 restores the original ECK polarity. Both latch outputs have real functional consumers and the new latch passes original-name LVS. An unmodified vendor simulation and fresh native SDF eliminate all 234 original warnings in the pilot’s 360-latch branch. A short waveform replay measures 315 ps from the new NAND CK fall to ECK fall and shows the original failing latch capture correctly without notifier transitions. The whole native-SDF run can still fail at untouched clock gates. Where a separate diagnostic moves the remaining missing delays into interconnect, state precisely which branches retained their native arcs and keep that run distinct from release evidence. Use the saved RC to size each other gate separately because the measured ECK wire loads span about 12–83 fF.

When two accepted local clock-gate replacements share CTS_736, compute endpoint and route changes against their common native base before applying either delta to the other candidate. SCE-139 checked each branch’s removals and additions at the mask level, including via enclosures, then re-extracted the merged root. Measure all existing and new gated-clock setup/hold, downstream macro pulse and I/O, and only then replay the original SDF. A passing diagnostic can isolate the remaining old-gate model errors, but a shared-clock merge cannot inherit either branch’s timing result or original post-simulation coverage.

A stopped simulation can hide later affected gate owners. SCE-144 used one native checkpoint, the unchanged vendor models, and subset diagnostics that redistributed only recorded falling delays. Correcting the first PRV branch still stalled. Restoring the seven owners that produced visible timing warnings gave all 5,760 output words and zero warnings, yet 14 words had a flipped high bit. Single-owner omissions reproduced disjoint groups of six and eight errors. Before selecting an ECO cohort, keep timing checks enabled and compare every checker word in an all-owner control and the narrower arms. A passing omission test establishes coverage only for the test image used in that arm.

Evidence: SCE-133 and SCE-144 in the MAIN ledger, including the saved-DB native path, SDF, full PAT0, and the two short VCS replays.
