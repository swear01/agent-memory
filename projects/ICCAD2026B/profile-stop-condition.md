# 生成工作的停止條件應對準最終 profile 指標

歷史助手先把單一 config 補到固定 accepted case 數當成 bulk run 目標，後承認把手段誤當目標；真正要求是兩個 profile 的 exact minimum 都低於既定門檻。

啟動長時間生成前，把終止條件寫成最終交付指標，單一 bucket 配額只作內部手段。發現目標錯置時保留已接受 evidence，修正後續排程；不能用完成某個配額宣稱整體目標達成。來源沒有最終 profile 達標結果。
