# 完成數只能由正式通過關卡的帳本計算

## Problem

歷史對帳找出 derived matrix 顯示剩 38，但 strict ledger 是 39；差異來自仍隔離且 DVC promotion 失敗的工作。

## Durable rule

從權威帳本推導完成數，將候選、條件性替換與失敗 promotion 分開；修正衍生報表，不可用較樂觀數字覆蓋正式關卡。

## Boundary

限此歷史案例及相同條件；不能覆蓋目前任務授權或最新專案規則。
