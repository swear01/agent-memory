# 整合驗收要列明方法、資料與文件的覆蓋

歷史助手回報合併一個分支並選擇性移植另外兩人的程式，刻意排除部分報告、資料及方法；使用者提醒要求的是方法、資料與文件完整整合。

按當次目標列出各來源的已在基線、採用、保留待查及明確排除項目，讓方法與證據、文件互相對應。建立 branch／PR 或局部測試通過不代表整合範圍完整；來源明列 runtime A/B、平台 artifact 等 pending，不能反過來說它已謊報這些 gate 通過。
