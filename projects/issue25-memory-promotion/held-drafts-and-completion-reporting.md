# Issue25 關卡通過仍須明說尚未解決的草稿

本次控制者在 G13–G16 通過且已發布筆記完成 QMD 回讀後，用「全部完成」和「已結案」概括狀態。使用者追問 462 份暫留草稿，才補充它們尚未全部修整解決。關卡採用的是允許明確保留未解紀錄的處置政策；通過這種關卡不能推導每份候選教訓都已完成來源修正或發布。

回報必須同時列出已發布與已驗證成果、未解草稿數量、控制者查核程度及是否仍有工作執行。這次帳冊的 462 份分為 385 份讀過草稿但仍需修整、拆分或進一步來源核對，34 份有具體待修正問題，43 份已核對所選來源仍不足以支持完整結論。這是當次快照，不是固定配額；其中可能仍有值得保留的教訓，不能全部說成無價值或已解決。

正確說法是「本輪已確認筆記的發布與驗證完成，仍有具體未解草稿保留」，而不是省略未解部分後說目標全部完成。保留原始來源與帳冊不等於已提取其中所有有價值資訊；粗略抽查、沒有運行中的 worker 或軟體驗證通過，都不能證明完整召回或內容保留比例。來源不足、混合獨立事件及尚待修正須分別交代，不能用不宣稱完整召回一句話掩蓋已知待辦。
