# 機器種類不應被速度變體拆成不同名稱

使用者更正 furnator 各變體屬同類，只是速度不同，玩家可見名稱應沿用 furnator，不能改成自行推測的 fuel 或錯誤分類。

先核對原模組的種類與變體關係，再決定分組與標籤；速度差異不自動等於另一種機器。來源沒有修補或 GUI 驗收結果；同則訊息的版面對齊及重複資訊要求另留，不視為此筆記已涵蓋。
