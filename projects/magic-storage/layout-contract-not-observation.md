# 版面測試不能把目前座標當成需求

歷史原始碼分析指出，自適應版面只保證不超出螢幕，沒有保證邊距與置中；SelfTest 還要求小解析度下 topPos == 1，將貼近螢幕邊緣的行為固定為通過條件。

版面契約應來自產品要求，明確定義最小邊距、置中容差及子元件包含關係，再在代表性解析度驗證。當使用者回報版面不對，應先重查契約，而不是把剛量到的座標寫成新預期值，讓錯誤繼續通過。

來源是歷史靜態分析片段，沒有本次 build、測試或視覺重現；上述契約是修正方向，不代表當時已實作或通過全螢幕驗收。
