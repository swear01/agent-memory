# 請使用者測 GUI 前先核對版本、啟動狀態與測試項目

## Problem

Agent 已請使用者測試，但隨後承認遊戲未開且部署版本落後；另一則承認未先說清驗證項目。

## Durable rule

交接前確認目標版本已部署且場景已就緒，逐項列出當次目視檢查；精確數值與可重複操作交由自動測試，不要求人工計時。

## Boundary

限此歷史案例及相同條件；不能覆蓋目前任務授權或最新專案規則。

## Verification

控制者核對了保留的歷史來源片段。上述現象、使用者糾正或負面結果來自該記錄；本次未重新執行當時的測試或修復。來源未證明的原因與修復成功不予採用。
