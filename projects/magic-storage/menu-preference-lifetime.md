# 每個 Menu 狀態隔離不等於玩家偏好持久化

歷史助手先回報自動檢查通過，後來承認排序、搜尋及資源顯示等狀態只屬於每次開啟的 Menu；使用者要求像 AE2／RS2 一樣持久保存。

先明確區分元件實例、單次開啟、玩家及跨重啟的狀態生命週期，再驗證關閉重開與不同玩家的行為。來源沒有完成持久化的證據，當次 GUI 又因顯示環境受阻；不能把自動測試通過當成實機驗收。
