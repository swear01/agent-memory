# UI 契約改版後同步 active 文件與驗收清單

歷史唯讀 audit 指出 UI 已從三頁改為四頁，但多份 active docs、Patchouli 入口與測試世界清單仍描述旧 Fuel 分頁或舊 hotbar 狀態；同時有些 checklist 已更新，不能一概稱全部漏改。

沿著受影響的入口、規格、操作文件與 fixture 清單核對同一契約。保留有日期的歷史測試數字與仍正確的內部識別碼，只修正現行描述。來源是靜態盤點，沒有重新執行 runtime，也沒有完成文件修改的證據。
