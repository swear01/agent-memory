# 交接 GUI 驗收前先準備必要物料

使用者要求先把機器與儲存區的必要材料放好，最後只需檢查，避免逐個手動放置；歷史助手回報重新建立場景並列出驗收項目。

讓當次驗收場景具備可直接操作的輸入與資源，對照需求檢查內容而非只確認 READY。來源另回報修正無效 inventory slot 與多套測試通過，這些都是歷史自述；沒有使用者最終目視核准，也不把關閉全螢幕順序套用到所有環境。
