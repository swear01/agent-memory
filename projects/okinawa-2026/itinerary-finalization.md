# 沖繩行程定稿與備選顯示偏好

- 使用者已接受目前五天行程、每日明確出門與回飯店時間，以及 Opus 5.5 重構後的地圖圖釘。這是已認可版本；後續維持設計與行程，僅處理使用者指定的改動。
- 行程與地圖合併一頁，交通路線固定顯示。選取地點不重設地圖視野。
- 餐廳備選直接放在對應用餐行程旁，不在每日最底下另列「備選」區塊；尤其不需要11/7頁尾的獨立備選清單。保留有空再逛及地圖備選資料，不能因刪掉頁尾展示就擅自刪地點。
- 文件、清單與地圖只保留會影響使用或決策的資訊，不加重複說明、操作紀錄或例行提醒。
- BOOKOFF 加排案因步行過遠已否決，只保留地圖參考，不得當作已採用行程。
- 主資料與模板為工作目錄的 `work/okinawa-itinerary-data.json`、`work/okinawa-itinerary-template-v2.html`；正式成果是旅行資料夾的 `沖繩五天行程.html`。下次先讀現有檔案，不能用舊備份重建。
- 後續 UX 工作預設交 Claude Code Opus 5.5，依 Impeccable；臨時授權 Codex 修改單次問題，不代表永久取消此分工。
