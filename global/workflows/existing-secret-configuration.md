# 已配置的密鑰先查來源，不要求使用者重建

跨機器部署時，助手因找不到預期密鑰檔而要求使用者提供路徑或建立檔案；使用者更正憑證已放在 shell 環境，當次需求是將既有設定部署到已授權的其他機器。

先核對已知設定來源與任務邊界，再宣告缺少憑證。檢查與搬移不得把密鑰值印進日誌、對話或記憶；既有部署授權只適用指定目標。來源未提供跨機器部署或驗證結果。
