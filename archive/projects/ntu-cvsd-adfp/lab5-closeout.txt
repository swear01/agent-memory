# Lab5 紀錄（2026-11-18）

- Lab5 是 Innovus APR 三次 lab 的第 1 次，只做到 floorplan：import（CHIP.v、4 個 LEF、CHIP.ioc、mmmc.view）、globalNetConnect VDD/VSS、`specifyScanChain`+`scanTrace`（1 條、1574 bits）、`floorPlan -r 1 0.7 80 80 80 80`、SRAM `RF2SH64x16` 放 core 左下 +30/+30、halo 30。Checkpoint 只有 floorplan 截圖；抽查名單 20 人，使用者不在內，截止 11/17 20:10。
- 課程預期在 ADFP 跑（講義 `% cb` → `% innovus`）。這次改在 gups 跑：`source /cad/cadence/CIC/innovus.sh`，`xvfb-run -a innovus -files <tcl>` 可用 `gui_dump_picture` 截圖。DVLab fleet（cthulhu、mazu）的 Innovus 25.10 啟動即失敗：缺 64-bit `libXp.so.6`（只裝了 `libxp6:i386`）。
- Placement grid 是 x 0.46（TSM13SITE 寬）× y 0.41（金屬 pitch，不是 row 高 3.69），原點 (0,0)。`floorPlan -r` 讓 core 對齊但 die 右上 x=1058.82 不在格上（IMPFP-7235）；`floorPlan -d` 會重新置中 core 而改報 IMPFP-7237；`setFPlanMode -snapDieGrid placement` 已是預設、無效。可行解：保留 `-r` 的 core，die 角往上取整到格子，`floorPlan -b die io core` 一次指定（io = core ± 80）。`get_snap_grid_info` 必須帶 `-type placement` 與 `-pitch_x`/`-pitch_y`/`-origin`。
- 腳本陷阱：`dbGet head.sites.size_x` 第一個元素可能是 246 µm 的 corner site，要用 `top.fPlan.rows.site.size_x`；macro 用 `dbGet -p2 top.insts.cell.name RF2SH64x16` 找（`cell.subClass block` 抓不到）；Innovus 25.1 沒有 `setInstancePlaceStatus`，改 `dbSet $inst.pStatus fixed`。
- COOL 附件：Brave 會擋同頁第二個自動下載；用 `domains/other/ntu-cool-api-access.md` 的 `public_url` + `curl -L` 最省事（這次繞了 base64 分塊）。
- 成果在 CVSD2026 repo `lab5/`（PR #22、#23）；TSMC library 不入 repo。
