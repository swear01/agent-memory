# 混合清理與唯讀檢查被拒絕時，不可聲稱檢查已跑

## Problem

歷史多步命令含清理與程序／帳本檢查，在 spawn 時因 rm 政策被整體拒絕。

## Durable rule

先確認命令是否真的啟動；可獨立執行仍獲授權的唯讀查核。被拒絕的刪除範圍需另外處理，不能靠換工具繞過限制，也不能聲稱後段檢查已執行。

歷史來源保留當時觀察，未重跑或驗證修復。
