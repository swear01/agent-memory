# 移除外掛要核對 live 登錄與還原來源

使用者要求其他機器若有外掛也一併移除，保留對話紀錄並處理相關文件；歷史助手盤點多個 agent 安裝點、還原來源與仍含 plugin 的 live 設定，卻又建議保留歷史文件。

依使用者最新指定範圍區分外掛、文件與對話，核對啟用登錄及會重新安裝的 canonical 宣告。來源清空未必刪除 live 欄位，舊 session 也不能證明新啟動已無外掛。來源只有盤點與提案，沒有各機移除結果；不得用助手偏好覆蓋使用者的文件要求。
