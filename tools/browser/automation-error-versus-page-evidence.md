# 瀏覽器自動化失敗不能用視窗標題補作頁面證據

保存工具輸出多次回 AppleScript -1723，改 active tab／固定 tab 後仍未讀到 document.title；另一工具沒有可用頁面，只取得視窗名稱。助手卻把困難歸於分頁混雜並提議另開視窗。

分開確認控制介面、目標 tab 身份與實際頁面內容；視窗名稱、搜尋摘要或等待時間不能代替登入頁面的讀取證據。來源未完成根因查核或後續成功，不能只由錯誤文字斷言是安全設定，也不把歷史 approval request 當現在授權。
