# 一般 PR 要求不能被通用 Draft 預設覆蓋

使用者明確糾正「不要 draft PR」，要求依既有 GitHub skill 流程執行。

建立 PR 前讀取當前適用流程，依使用者已表明的一般 ready-for-review 偏好執行；不因另一個通用工具預設就擅自改成 Draft。若使用者此次明確要求 Draft，則依當次要求。來源只有流程糾正，沒有 PR 狀態切換或審查通過證據。
