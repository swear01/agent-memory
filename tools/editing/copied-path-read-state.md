# 讀過來源檔不代表編輯工具已讀過副本

對複製出的檔案執行 Edit 被拒絕，錯誤明確要求先 Read。歷史助手指出該 harness 依確切路徑追蹤已讀狀態，原檔讀過不能替代副本。

使用有先讀後寫限制的工具時，在修改前讀取實際目標路徑及相關區段；複製或移動後重新確認。這是該工具的路徑狀態邊界，不是所有編輯器的通則，也不表示檔內 bug 分析已通過驗證。
