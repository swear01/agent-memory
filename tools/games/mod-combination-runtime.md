# 功能不重複不等於模組組合能穩定執行

助手按功能不重複原則加入數個模組，重啟卻黑屏或卡住，清 shader cache 後仍不能確認穩定；使用者也回報遊戲卡死。

保留已知可運作的組合與設定，對新組合做實機驗證，將功能重疊研究與相容、穩定性結論分開。失敗時做有界隔離，不能把退回舊組合的建議當成已證實修復。來源没有確認根因或恢復成功結果。
