# 找不到一類來源時要保留已查與待查範圍

使用者要求查網頁存檔以補課程、出版、新聞與維護者資料；歷史助手只找到成員 JSON 與照片的上游提交來源，其餘四類仍未找到。

依類別記錄已查來源、可取回範圍與未完成工作；不要把找到成員資料當成網站資料全部齊備。沿使用者指定的存檔線索继续查時保留歷史日期，不能把舊頁面直接當現況。來源沒有存檔搜尋結果或資料更新完成。
