# 引用 DOI 前核對 concept 與 version 身分

歷史助手承認把 version DOI 說成會指向最新版，讀取該筆記錄後才分清 concept 與 version DOI。

從實際記錄 metadata 核對識別字及引用目標，不靠相鄰數字或記憶猜測。修改檔案、修改 metadata 與建立新版本應按目前典藏平台規則另查。來源沒有新版本發布結果，也不能採用「小瑕疵不影響評分」這類未經支持的保證。
