# 正式信件要保留必要關係，刪去收件者已知的成果

使用者連續糾正信件太長、重複列出老師已看過的成果，並要求明講一項影響指導關係的背景。

依收件者已知資訊與使用者明確要求整理短版，不因濃縮而省略必要揭露。這是當次寫作糾正，不是所有正式信件的固定格式；來源沒有最終採用或寄出結果。
