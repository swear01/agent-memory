# 目錄層清單不能用來判定巢狀檔案不存在

歷史助手使用非遞迴 ls-tree，只列到目錄卻把巢狀模組全部判為 absent；來源後續提供遞迴檔案清單與重新計算的分布。

確認列舉實際到達所查檔案，或直接查詢確切 tree path，才做存在性統計。保留 commit 身分與查詢範圍；修正後統計不可再當成原先錯誤的數字。這項教訓只涉及列舉方法，不替其他實驗基底選擇作結論。
