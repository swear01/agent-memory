# 跨 repository 變更須逐項交代提交歸屬

使用者追問一批未提交變更要放到哪個 Git，助手才分清實作在 shared-skills、回歸測試與 submodule 指標在 transfer_MAC。

提交與交接前逐項對照檔案所屬 repository、實作 commit 與父 repository 的 submodule pointer。分別驗證同步狀態，不把多個 repository 概括為同一批已保存或未保存。

来源支持歸屬釐清，沒有此片段中的最終同步證據。是否寫入某種記憶系統依當次規則與已有授權，不加新的通用確認流程。
