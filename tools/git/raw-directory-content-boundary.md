# Raw 目錄清理必須依內容與授權範圍

歷史清理記錄把 retired results 目錄視為 raw 資料，但唯讀盤點找到 406 個 Markdown 檔，列出的檔名包括分析摘要、案例與驗證紀錄。使用者授權刪除 raw，Agent 因此收窄刪除範圍並保留這些文件。

目錄名稱、體積及 ignore 狀態不能證明內容都可丟棄。清理前列出實際檔案與內容類型，依授權目的區分 raw 輸出、分析結論及設計文件，保留無法確定的項目。副檔名只能幫助盤點，不能保證價值或刪除安全。

來源支持盤點結果與修正後的清理邊界；不支持零誤刪保證，也沒有證明後續刪除已執行完成。
