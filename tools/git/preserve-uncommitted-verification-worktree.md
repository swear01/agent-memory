# 驗證中的未提交工作樹不得清除

## Problem

歷史狀態記錄指出，修正工作樹在驗證途中被移除，未提交修改沒有留在 branch 上，只能重新建立；使用者要求繼續重做。

## Durable rule

清理工作樹前，確認它已停止使用、狀態乾淨且修改已有可驗證的保留位置。分支名稱存在不代表未提交內容已保存；有未提交或仍在驗證的內容就保留原工作樹。

## Boundary

適用於 agent 工作樹生命週期。來源支持遺失與重做需求，不支持後續重建已成功。

## Verification

控制者核對了保留的歷史來源片段。上述現象、使用者糾正或負面結果來自該記錄；本次未重新執行當時的測試或修復。來源未證明的原因與修復成功不予採用。
