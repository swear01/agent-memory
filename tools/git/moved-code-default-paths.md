# 程式碼搬移後核對呼叫點與預設路徑

歷史助手在批次搬移後發現不同寫法的 repo_path 呼叫、測試常數及巢狀 pr_gen 模組預設路徑仍指向舊位置或少一層目錄。

路徑遷移不能只靠一次字串替換。沿入口、不同參數形式與預設值查所有受影響消費者，按實際新位置驗證解析結果，再跑受影響流程。來源只有漏改發現與修正計畫，沒有遷移後通過證據。
