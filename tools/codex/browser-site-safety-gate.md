---
title: 內建瀏覽器開頁與 site-safety 授權須分開確認
scope: tools/codex
status: active
updated: 2026-11-01
---

2026-11-01 Humble Choice 操作中，內建瀏覽器可列出結帳分頁，但讀取 DOM 時回報 `The site-safety policy blocks this action`，並明確禁止透過其他瀏覽器控制面、raw CDP 或間接執行達成同一操作。這是當次觀察，不代表該網站永久被封鎖。

- 開頁請求回報 `queued` 只證明請求排隊；分頁網址、使用者已登入或已付款，都不等於 agent 已取得頁面讀取與操作授權。
- site-safety 明確封鎖時，停止該操作，不把它當成一般連線逾時，也不換控制工具繞過。交由使用者自行處理，或採用封鎖回覆允許的較安全替代方式。
- 使用者後來回報已自行付款並兌換完遊戲；這是使用者回報，不能寫成 agent 已兌換或已驗證帳號遊戲庫。
- 查促銷時要核對活動日期、優惠碼與新／舊訂閱者資格。不同來源的代碼可能不一致，搜尋結果不能代替登入後結帳試算；不把短期優惠保存成長期有效規則。

本次沒有完成 agent 端的序號讀取、Steam 啟用或遊戲庫驗證。記憶不得包含收據驗證參數、序號或帳號識別資料。
