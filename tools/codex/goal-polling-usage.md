長期目標每次自動續跑，即使只是查背景工作，也會喚醒模型並重送上下文。快取 input 仍可能消耗帳戶用量。分開核對獨立背景程序、喚醒頻率、單輪上下文、當次模型及帳戶用量窗口；帳戶共用的增量不能全歸給單一工作。

背景程序仍健康時，優先用批次完成、錯誤或需介入等事件喚醒。缺乏事件時採有上限的低頻心跳，正常進度保持靜默。對一次性工作按當前任務驗到終點，不把監控直接改成日後週期排程。

舊案已讀回目標狀態與較低頻率設定，但沒有等滿區間驗實際觸發。日常應分開回報設定、實際喚醒和背景產物。[歷史量測與快照](https://github.com/swear01/agent-memory/blob/f4e2dfbea776667f5b468d76c07353fb4e0977a4/tools/codex/goal-polling-usage.md)
