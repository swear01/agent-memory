---
title: Codex 長期目標的輪詢用量
scope: tools/codex
status: active
updated: 2026-09-25
---

長期目標若每隔幾分鐘自動續跑，即使只是檢查背景工作，也會反覆呼叫模型並重送長上下文。2026-09-25 一次媒體遷移任務的唯讀紀錄顯示：使用 GPT-6 Astra，約 17 小時內自動跑 476 輪、累積約 5.34 億 input tokens，其中約 5.30 億命中快取；同期間帳戶 7 天共用用量由 17% 升至 65%。其他同帳戶工作也可能佔一部分，不能直接把 48 個百分點全歸因於該任務。

診斷時分開看背景程序是否有實際進展、模型喚醒頻率、單次上下文大小、模型選擇與帳戶用量視窗。背景複製程序持續運行，不表示要讓 Codex 每 1–3 分鐘重新推理一次；快取 input 仍有額度成本。優先讓程序自行運作，僅在批次完成、錯誤或需要介入時喚醒；無事件通知時用有上限的低頻心跳。用量百分比和工作進度只當即時快照，重新查證後再引用。

2026-09-25 使用者同意降低輪詢成本。執行任務的 `update_goal` 回傳 paused，任務狀態讀回 idle；監測心跳設定讀回 ACTIVE、`FREQ=HOURLY;INTERVAL=2`（原為每 10 分鐘），正常進度保持靜默。設定及暫停狀態已驗證；未經過完整兩小時，後續實際喚醒頻率與背景程序持續進展仍需另行確認。
