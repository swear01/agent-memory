# 使用者限定 Major／Blocker 時不要再展開 Minor 清單

使用者明確要求立即結束，只列 Major／Blocker；歷史助手雖說 No Major，仍列兩項 Minor 及長篇安全摘要。保存來源另混有完全不同作業文件的審查。

遵守當次範圍、嚴重度與停止要求，簡述必要證據及未跑的驗證即可。不要因相鄰紀錄就把作業格式問題歸入同一 code review，也不能把只讀檢查稱為 runtime 安全證明。來源没有後續格式修正結果。
