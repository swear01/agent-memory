# 只讀 status 面板不應自行加上 Stop 或 Re-run

使用者要求 status 面板只顯示狀態、不需操作按鈕，並納入 background terminal；歷史助手方案仍列出 Stop 與 Re-run。

依使用者要求以既有活動資料呈現持續工作、狀態及必要來源，不擅自擴張成另一套 process manager。是否可查看輸出等導覽與是否能改變程序是不同權限。來源只有設計提案，沒有面板完成或驗證結果。
