# 隱藏 Agent 按鈕不同於隱藏表單欄位

使用者要逐一控制不同 Agent 是否出現在 Create Session；助手卻做了 Machine、Model、Effort 等表單欄位的隱藏，後承認 PR 範圍錯置。

先確定被控制的實體、作用位置與使用者要消除的干擾，再設計設定。不要把同一頁面的相鄰元件當成同一需求。來源只有糾正與重做提案，沒有新 PR 或功能驗收結果。
