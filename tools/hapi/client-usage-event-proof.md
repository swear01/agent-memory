# Usage 接收介面存在不代表每個 client 都有送資料

歷史助手先誤查 Happy，改答 HAPI 時列出 generic usage 路徑，使用者仍追問各 client 實際會不會回傳。

分別核對目標 client 的原始 usage 事件、轉換、保存與報表結果。接收端程式與「只要有回傳就支援」的條件句不能作為已涵蓋該 client 的證據。來源沒有定位缺失 client 或端到端修補結果。
