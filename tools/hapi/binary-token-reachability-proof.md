# Binary 找到 steering 字串不等於 SDK 可觸發

歷史助手先因 steering 字串改口宣稱功能存在，接著又因 stream-json 附近搜尋空白而推論只限 TUI；保留片段包含一般模型描述及多種不一定相關的 steer token。

分開確認字串含義、實際呼叫路徑與對外 schema，再以對應 runtime 驗證能力。有字串不能證明功能可達，鄰近關鍵詞搜尋沒命中也不能證明 API 不支援。來源未完成該驗證，因此不保存 Claude 特定版本是否支援 steering 的結論。
