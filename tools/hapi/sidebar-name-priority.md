# 窄側邊欄先保留可辨識的名稱

使用者回報 HAPI 側邊欄變窄時，資料保留優先級不對，名稱幾乎不可辨識，並明確要求至少保留一定名稱長度。

響應式欄位應先決定識別資訊的保留優先級，再安排其他資訊截斷或縮減；不能只讓欄位平均擠壓。以實際窄寬度檢查名稱仍可辨識。來源只有使用者要求，沒有修補、最小長度數值或視覺驗收結果。
