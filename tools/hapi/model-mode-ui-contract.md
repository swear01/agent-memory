# Agent 設定排序要先符合模式語意與使用者要求

歷史助手把 OpenCode Model 放到 Permission Mode 前面並列出測試通過；使用者明確要求 Model 在 mode 下方，並要求核對 OpenCode 的實作模式。

核對各 agent 的 permission、collaboration 與 model 欄位語意，再依當次要求呈現。測試全綠不能代表排版需求正確。來源最後自述改回 mode 下方，但沒有後續畫面或實作驗證，也不推廣成所有 agent 的通用排序。
