# 口語產品名先對照實際元件再診斷

歷史助手曾把含糊的 PyAgent 稱呼解讀成 HAPI 中一個同名元件；隨後重讀先前查核才更正 repo flavor 是 pi，並非假設的 PyAgent。

以實際安裝產品、repo 元件與既有查核結果釐清口語名稱，再追呼叫路徑；不要從名稱相似就宣布根因。來源未確認誰指定了後續模型，不能沿用相鄰訊息的必然推論。
