# 分享預覽前確認服務正在提供最新產物

使用者回報看不到 mockup server；助手稱服務已停，重啟後又懷疑複製檔案未觸發 watcher，最後另提供截圖。

分享預覽時核對服務存活、可達 URL 與實際回傳內容是否為最新版本。需要長時間審閱時保留可用的静態交付，不只留下易失效的暫時連結。來源沒有證明 idle timeout 或 watcher 是根因，也沒有穩定預覽的驗收結果。
