# 所有視窗都無反應時先查自動化觸發

歷史助手先猜遊戲按幀率讀取滑鼠，調長按住與點擊間隔並重啟 Hammerspoon；使用者隨即更正，每個視窗都完全無反應。

先取得快捷鍵、腳本執行與必要權限的直接證據，再診斷特定應用的輸入時序。調整參數或重啟的自述不能代表輸入成功；來源沒有確認真正的 setup 根因或恢復結果。
