# Crawler 成功狀態不能代替取得可評內容

歷史評分先用了截圖，補走標準 crawler 後雖顯示 OK，raw 卻只有登入牆，未取得要求評閱的正文；助手因此撤回先前暫評。

正式評分先依既定來源取得流程核對 raw 內容及範圍。登入牆代表內容取得失敗，不能當成學生沒有提交內容，也不能用 crawler 的成功退出碼確認爬取完整。來源未提供後續取得正文與重評結果。
