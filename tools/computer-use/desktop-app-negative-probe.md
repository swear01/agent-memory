# 應用名稱查詢失敗不能當成已取得遊戲畫面

## Problem

歷史 Computer Use 以 Minecraft 名稱查詢得到 Invalid app；改查 launcher 識別碼又逾時。

## Durable rule

確認工具實際列出的應用與目標畫面；名稱查詢失敗或逾時都不能當作畫面驗證成功。這份證據沒有成功截圖，也不能宣稱改用識別碼已修好。

## Boundary

限此歷史案例及相同條件；不能覆蓋目前任務授權或最新專案規則。

## Verification

控制者核對了保留的歷史來源片段。上述現象、使用者糾正或負面結果來自該記錄；本次未重新執行當時的測試或修復。來源未證明的原因與修復成功不予採用。
