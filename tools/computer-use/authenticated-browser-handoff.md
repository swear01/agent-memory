委派登入後操作時，交代允許沿用的瀏覽器、既有 session 和目標頁，接手後先讀到實際頁面。瀏覽器名稱相同、打得開視窗或出現目標頁標題，只能作定位線索。

AppleScript 回 `-1723`、`document.title` 讀不到、工具沒有附著頁面時，分別核對控制介面、tab 身分與實際頁面內容。用成功讀到的內容或所需操作確認授權狀態；交接不複製 cookie 或繞過限制。
