# 委派瀏覽器工作須沿用已授權登入狀態

## Problem

使用者指出，部分受委派工作開了新的未登入瀏覽器，沒有使用指定的既有瀏覽器 session，導致需要登入的頁面無法存取。

## Durable rule

交接需要登入的瀏覽器工作時，明確交代指定的瀏覽器、可使用的既有 session 與目標頁，先確認實際可讀到所需內容。工具名稱相同或成功開頁，不代表沿用了授權登入狀態。

## Boundary

只有已獲授權的既有登入狀態可沿用；不以複製 cookie 或繞過存取限制代替正確交接。來源支持使用者糾正，未證明所有受委派工作都已修復。

## Verification

控制者核對了保留的歷史來源片段。上述現象、使用者糾正或負面結果來自該記錄；本次未重新執行當時的測試或修復。來源未證明的原因與修復成功不予採用。
