# 批內無重複不能擴大成全歷史唯一

## Problem

協調者記錄缺少可信全域 log-hash index，且完整 evidence pool 掃描未獲授權，只能證明批內無重複。

## Durable rule

明確記錄去重查核範圍；完整歷史唯一性保留為待驗證條件，不能以局部成功宣稱全域通過。

## Boundary

限此歷史案例及相同條件；不能覆蓋目前任務授權或最新專案規則。

## Verification

控制者核對了保留的歷史來源片段。上述現象、使用者糾正或負面結果來自該記錄；本次未重新執行當時的測試或修復。來源未證明的原因與修復成功不予採用。
