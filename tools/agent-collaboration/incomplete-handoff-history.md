# 接手片段為空時先查較早紀錄

助手只看到被引用 session 的方案升級提示，就要求使用者重述任務；使用者更正應往前多看對話。

接手紀錄缺少任務正文時，先沿已知 session 或工作區查較早的摘要、交付物與指令，再判斷仍缺什麼必要資訊。不要把單一空片段當成整段歷史不存在。來源沒有後續還原成功的證據。
