# 對帳方式

- 先核對月份、欄位、既有值與原始收據，再寫入實付金額；含稅收據用實付總額，不取未稅小計。未找到收據不代表支出為零，也不能直接沿用舊價格。
- 電信應繳總額可能包含上期延繳款。按帳單月份記錄當期新增費用時，以前後期帳單的併帳通知核對並扣除已歸屬前月的金額，避免重算；不要混用付款月份與費用月份。
- 儲值通知若沒有金額，先取得使用者確認的每次儲值額，再用筆數粗估。儲值包含餘額變動或其他消費，不能稱為乘車明細。
- 同一筆支出從明細移至月表時，先確認日期、項目、金額與相鄰紀錄；目的金額讀回正確後移除來源紀錄，再核對兩邊。相同金額的不同收據不可當成重複信件省略。
- 本幣刷卡授權通知只是暫估，不等於最終入帳額。沿用既有記帳口徑，並在回覆中說明未核對的部分；使用者不要儲存格備註時，不新增備註或註解。
- 外幣收據須先確認記帳幣別；只有使用者同意估算後才換算。可取扣款日銀行營業時間最後一筆即期賣出牌價，非營業日取前一營業日；明確標示估算、匯率日期及未含刷卡手續費，不能稱為實際台幣入帳額。
- 多期訂閱按實付金額與方案期數攤提；360 天方案可按 12 個 30 天月估算，但付款日不一定是方案生效日，使用付款月份起算時須交代這項假設。已付款方案的未來月份屬預排攤提；沒收據的浮動月費應留白。

# 瀏覽器操作與驗證

- 依既有[瀏覽器與登入規則](../../global/workflows/authenticated-browser-form.md)，優先使用已授權的 Codex 內建瀏覽器。某個信箱查不到收據時，先核對訂閱所用帳號；缺少登入時只交接必要驗證，完成後接續原任務。
- Google Sheets 名稱方塊可定位範圍，再用一般複製／貼上讀寫。切換工作表後先觀察目前狀態；複製完成後另外讀回剪貼簿，避免取得前次複製的舊內容。
- 修改前後比對指定儲存格與相鄰值，確認沒有多改內容。看見已儲存到雲端後重新載入，再讀回金額；寫入成功回應或剪貼簿中的值單獨都不足以證明雲端保存。
- Google Sheets 匯出 XLSX 可能重排 sharedStrings 與樣式索引，XML 位元組不同不代表資料被改；比較原值、公式及解參照後的樣式，並渲染受影響範圍。不要為了驗證而把匯出副本覆寫回原表。
- GOOGLEFINANCE 的歷史資料不能透過 Sheets API 或 Apps Script 存取；需 API 回讀驗證的歷史匯率估算，可改用已核對的銀行牌價，不能把 #N/A 隱藏成零或成功。
- 共用記憶只留去識別化流程，不保存帳號、文件網址、收據、付款識別或個人逐筆帳務。專用偏好與私人來源留在本機。
