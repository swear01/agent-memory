# 服務限額衝突不能混合搜尋摘要成單一結論

保存搜尋摘要對同步 function timeout 分別給出互相衝突的數字，還把較小數字稱可升級限額；另一段稱固定不可配置，來源沒有統一日期、方案與 function 類型。

以當時官方具體產品／方案文件確認限制，分開 sync、background 與底層平台能力；不要用舊論壇摘要或底層上限替代託管服務契約。本筆記不選定任何數字作為現行限額，也沒有定價證據；生成草稿提到計價的部分不予採用。
