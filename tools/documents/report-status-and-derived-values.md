# 報告修訂後分別核對數字與提交狀態

歷史助手回報新版報告編成 11 頁並整理 submitted 殘留，保存的搜尋結果仍有 9 頁敘述與另一組增益數字；原文明確說論文尚未投稿，而 artifact 可能另有發布。

從對應版本與實驗帳本重新核對頁數、統計及狀態，分開維護文件修訂、artifact 發布與論文提交。不同數字可能屬不同實驗範圍，不能只為文字一致就覆蓋它們；來源沒有完成逐項對帳，亦不採用其中關於外部 API 能力的廣泛斷言。

若只是發布 artifact、沒有可追溯的投稿收據，別把論文標為 submitted。歷史誤標令後續策略誤以為只允許 post-submission addendum。更正後回查版本凍結、報告和派工是否仍引用錯誤狀態；沒有該案完成重整證據。[投稿狀態原案](https://github.com/swear01/agent-memory/blob/f4e2dfbea776667f5b468d76c07353fb4e0977a4/tools/documents/submission-state-provenance.md)
