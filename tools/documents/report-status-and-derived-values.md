# 報告修訂後分別核對數字與提交狀態

歷史助手回報新版報告編成 11 頁並整理 submitted 殘留，保存的搜尋結果仍有 9 頁敘述與另一組增益數字；原文明確說論文尚未投稿，而 artifact 可能另有發布。

從對應版本與實驗帳本重新核對頁數、統計及狀態，分開維護文件修訂、artifact 發布與論文提交。不同數字可能屬不同實驗範圍，不能只為文字一致就覆蓋它們；來源沒有完成逐項對帳，亦不採用其中關於外部 API 能力的廣泛斷言。
