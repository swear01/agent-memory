# 下載連結必須符合使用者所在前端

使用者在遠端前端無法開啟助手提供的 sandbox 連結；助手因而提出改用既有雲端硬碟交付，但片段沒有後續上傳結果。

交付時確認連結可由使用者的實際前端存取，優先使用已授權且可驗證的通道。產生檔案或提出上傳方案不等於使用者可下載；不要把前端專用路徑當成通用外部連結。
