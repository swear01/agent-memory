# 文字清楚與圖層不遮擋要各自確認

使用者指出亮背景上的字邊太淡；歷史助手回報加深底影與多層描邊、重新輸出且測試通過，使用者接著指出印章仍被 chart event 擋住。

分別檢查不同輸出尺寸的文字辨識與元素遮擋。Renderer 測試及尺寸正確不能代替實際視覺結果，特定描邊配色也不是通用處方。來源沒有使用者確認可讀性已改善，亦無後续遮擋修正結果。
