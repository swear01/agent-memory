# 文件重構要調和舊索引與交叉引用

助手新增文件結構後，發現舊 docs 索引仍指向過期版本、已搬移的規格及舊架構位置，形成相互競爭的入口；歷史工作紀錄中的舊路徑敘述則仍屬正確歷史。

重構文件時一併檢查既有索引與現行交叉引用，讓讀者能找到真正權威頁面。不要把所有舊路徑字串全域替換，也不要留下兩份互相矛盾的 active 目錄。來源停在判斷與修改計畫，沒有最終驗證結果。
