# 已授權調整表單時不要為保版面犧牲可讀性

助手曾為維持原表三列而把兩門課擠在同一列；使用者明確允許改版面、增加欄位並把字放大到不溢出。

將當次明確授權納入版面設計，讓各筆資訊可辨識，並檢查頁面溢出與必要欄位。這是特定表單的可讀性要求，不代表其他官方表單都可任意改版。來源沒有依新要求完成的版面驗收證據。
