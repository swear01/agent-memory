# 術語清理要重查同一概念的剩餘寫法

使用者只選擇釐清 T1 數字與 mask 比例簡寫；後續掃描雖已清掉部分確切字串，仍留下 BACKTRACK、Uniform T1 與 T1 differential 等相關寫法。

以核准的概念範圍整理變體並讀回語境，不能只檢查首個替換字串為零。保留未要求改動的標準術語與內部識別字，不把命中數直接当成一定要刪除的缺陷。來源沒有後續完整清理結果。
