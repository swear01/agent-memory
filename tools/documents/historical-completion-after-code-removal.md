# 檔案已刪除不代表歷史完成勾選當時是錯的

歷史助手發現 p040 plan 勾選已完成的 script 現在不存在，查 Git 後回報它曾加入、後因 Q2–Q4 路線退役一起刪除；真正問題是該歷史計畫仍被當成現行文件。

先核對新增、刪除與路線變更，再決定狀態及文件位置，不能直接把舊完成改成未完成或無依據重建 script。去掉死連結也不會自動修正現行狀態；來源只有調查與封存決策，未證明這份 plan 最後已完成搬移。
