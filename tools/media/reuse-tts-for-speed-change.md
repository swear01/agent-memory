# 已生成語音的加速要求先用既有音訊處理

使用者明確要求直接把已生成語音加速，並禁止再呼叫 ElevenLabs。助手表示原本計畫使用本地 ffmpeg，但在缺少 python alias 時中斷，自述並未再次送出 TTS 請求。

沿用既有音訊製作衍生檔，核對時長、影片與字幕同步，不因節奏調整擅自重新生成付費語音。來源不足以說先前真的重打 API，也沒有完成加速影片的證據；本地缺指令是另一項待修執行問題。
