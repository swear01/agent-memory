# 署名資料齊全與編排尚未決定要分開盤點

歷史助手承認把正式名單未定說得太廣：多組譜師已有素材來源，實際未定的是收錄、排序與時間表；使用者再補充企劃、影片製作與最終團隊署名。

逐欄記錄已確認資料、缺少來源及尚待決定的編排，不因其中一項未定就把整份名單稱為缺件。也不要把尚未詢明的工作人員直接排除；來源只有盤點與糾正，沒有最終 credits 成品核准。
