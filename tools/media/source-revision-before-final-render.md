# 來源修正會使既有定稿與剪輯切點重新待驗

歷史助手讀到素材 ADX 問題與錄影可能沿用錯誤設定，卻發現現行文件仍標完成並鎖舊來源；因此提出重新確認正式來源、版本與切點。

解碼通過只證明媒體可讀，不證明錄影所用資料正確。取得修正版後重新綁定來源 hash 並量測受影響的起點、卡片與音訊，不直接沿用舊時間。來源中錄影問題及分段署名仍屬待確認，兩段重複敘述不是獨立佐證，也沒有重製或远端發布結果。
